# 项目需求记录（2026-05-22）

## 当前进度
- 核心爬虫与数据管线已完成
- GitHub Actions 自动生成评价与索引已完成
- 展示索引的多维排序已完成

## 目标
为同学提供一个由上过课的同学给出的通识课课程质量评价平台。

## 展示
- 使用 GitHub 托管源代码（Markdown 文件）。
- 使用开源文档构建框架生成静态站点。
- 部署到 GitHub Pages（github.io）或 Cloudflare Pages。

## 贡献
- 贡献者通过提交 Issue 或 PR 进行评价贡献。
- 设计 Issue 或 PR 模板，指导贡献者填写。
- 使用 GitHub Actions 从 Issue/PR 中抽取信息，生成结构化 Markdown 文件，并触发静态站点构建。

## 模板要求
- 标题需格式化。
- 使用标签（tag）。
- 主体包含：
  - 课程唯一标识：课程号-课序号（与官方开课数据匹配）。
  - 评价打分（1-7）。
  - 具体评价内容。

## 实现细节
- 事先获取学校官方开课数据，保存为 JSON，供 GitHub Actions 匹配。
- 数据字段包含：
  - 开课院系、课程号、课序号、课程名、学分、主讲教师
  - 本科生课容量、本科生课余量、研究生课容量、研究生课余量
  - 上课时间、选课文字说明、课程特色、年级
  - 是否二级选课、实验信息、重修是否占容量、是否选课时限制
  - 通识选修课组
- 确定项目结构与使用的文档框架。
- 确定使用 Issue 还是 PR，并编写 GitHub Actions 流程。
